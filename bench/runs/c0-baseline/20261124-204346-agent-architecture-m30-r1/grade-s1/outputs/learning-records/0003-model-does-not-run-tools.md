# Misconception to work on: the model runs the tools itself (M4)

In quiz 0001 (s1), Riley said the model opens the booking system and "runs the 3 tools itself" in one call (q2, q4). They also said the model remembers its tool choices across sessions (q6, M3). Riley does know the loop's shape, that a step limit stops a stuck loop, and that the model chooses tools from their descriptions.
Next lessons should separate what the model outputs (a request) from what the program does (runs the tool, returns the result). Memory should be taught as the program saving and re-supplying information.
