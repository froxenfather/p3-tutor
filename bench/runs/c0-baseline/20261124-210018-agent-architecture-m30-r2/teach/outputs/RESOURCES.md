# Agent architecture Resources

## Knowledge

- [Anthropic: Effective context engineering for AI agents](https://anthropic.com/research/effective-context-engineering-for-ai-agents)
  Primary source on keeping the window small, notes and just-in-time retrieval. Use for: deciding what an agent keeps in context.
- [Claude docs: Context windows](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  How the window works, sizes by model, long-context pricing, quality at length. Use for: budget and cost planning.
- [Claude docs: Memory tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/memory-tool)
  Notes as files that persist between sessions, with storage handled by your application. Use for: between-session memory design.
- [Anthropic: Managing context on the Claude Developer Platform](https://www.anthropic.com/news/context-management)
  Context editing plus the memory tool. Use for: clearing stale tool results.
- [Anthropic: Introducing Contextual Retrieval](https://anthropic.com/research/contextual-retrieval)
  Chunking, keyword plus embedding search, and chunk context. Use for: making the manual search accurate.
