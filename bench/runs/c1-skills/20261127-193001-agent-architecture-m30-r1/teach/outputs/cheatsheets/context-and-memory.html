Context and memory

Full lesson

Terms

TokenUnit of text the model reads and writes
Context windowAll text referenceable on one call, output included; limited
Context rotRecall tends to worsen as context grows
Short-term memoryOne conversation's history, kept and resent by the program
Long-term memoryStored outside; saved and reloaded across sessions
CompactionSummarize history, continue from the summary
Note-takingAgent writes notes outside the window, reads them later
RetrievalSearch a store, insert only relevant pieces

Where does each fact go?

If it is...Then...
Needed on every call, small, stableSystem prompt or tool definitions
Part of this taskMessage list
Changing or officialLive tool lookup
Large, mostly irrelevantRetrieval
Useful later, recorded nowhere elseDated long-term note

Cost of a multi-step request

Total input = sum of every call's input. A result added early is paid for again on each later call.

Retrieval pipeline

Chunk → index → search (keyword, embedding or both) → insert top-k with source labels.
